# Tranzl 0.2.3

Bug fixes and translation display improvements for Apple Silicon Macs.

- Fix image pasting from clipboard managers that restore images using native macOS clipboard formats, in both Translate and Chat.
- Improve image translation instructions so models translate readable text into the selected language instead of stopping at transcription. Preserve custom editing and original-language modes, accompanying text, and table structure where possible.
- Enable thinking for embedded image translation in Balanced mode; Fast continues to disable it.
- Render translation results as sanitized Markdown, including tables, lists, emphasis, and code blocks. Copy retains the underlying text. Chat and Translate share the same Markdown sanitization.

The embedded inference architecture and platform support are unchanged. Windows, Linux x64, and Linux ARM64 support remain planned after the single-runtime evaluation.

Install:

```sh
brew install --cask zoltanf/tranzl/tranzl
```

Upgrade:

```sh
brew update
brew upgrade --cask tranzl
```

The Mac app remains ad-hoc signed, not notarized; the Homebrew cask removes its quarantine attribute as documented in the README.
