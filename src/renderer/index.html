Tranzl

Tranzl is a translation and text-editing tool that runs entirely on your Mac. Type or paste text and it is translated as you go — or proofread, rewritten in a different tone, simplified, or transformed with your own custom prompt. Nothing you type ever leaves your machine: all processing happens locally.

How it works

Translations are produced by a large language model running on your own hardware, through one of three interchangeable backends:

  • Embedded — Google's Gemma 4 E4B model, downloaded once and run inside Tranzl with Metal acceleration on Apple Silicon (via llama.cpp). No other software needed.
  • LM Studio — uses a running LM Studio server at 127.0.0.1:1234 and whatever model it has loaded.
  • Ollama — uses a running Ollama server at 127.0.0.1:11434 and the models pulled with it.
